🔥 Firebase — Instrucciones de configuración

Para activar el guardado de encargos y configuración en la nube:

  1. Ve a console.firebase.google.com
  2. Crea un proyecto o usa el mismo de tu tienda
  3. Activa Realtime Database y Storage
  4. En encargos.html reemplaza firebaseConfig con tus credenciales
  5. Haz lo mismo en admin-encargos.html
  6. En Realtime DB, crea la ruta config/encargos con los valores iniciales
config/encargos: {
  "multiplicador": 1.8,
  "envio": 8000,
  "domicilio": 0,
  "whatsapp": "573001234567",
  "moneda": "COP"
}
